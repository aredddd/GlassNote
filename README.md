# GlassNote

基于图层覆盖技术的网页标注浏览器插件。

## 🚀 快速开始

### 🌟 v2.0 重大升级！

**全新架构特性：**
- ✅ **DOM内联标注** - 标注直接嵌入网页HTML，彻底解决滚动错位
- ✅ **智能路由检测** - 自动感知页面变化，按需询问是否加载标注
- ✅ **非侵入式启动** - 不自动启动，只在有标注数据时友好提醒
- ✅ **多重定位保障** - DOM路径+文本内容双重定位，高容错率
- ✅ **完美兼容滚动** - 标注随页面元素自然移动，告别定位错乱

**核心功能：**
- ✅ 文本选择和多种标注类型（高亮/加粗/下划线/彩色）
- ✅ 智能文本包装（自动检测跨行、避免重复标注）
- ✅ 本地数据持久化（优化数据结构，更高效存储）
- ✅ 优雅的用户交互界面

### 安装方法

1. **下载源码**
   ```bash
   git clone https://github.com/aredddd/GlassNote.git
   cd GlassNote
   ```

2. **在 Chrome 中加载扩展**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择 `GlassNote` 项目文件夹
   - 扩展将出现在扩展栏中

3. **开始使用**
   - 访问任意网页（如 GitHub、文档站点等）
   - 正常浏览，系统会智能检测路由变化
   - 如果页面有标注数据，会弹出友好询问对话框
   - 选择"加载标注"开始使用

### 🎯 使用指南

**智能启动流程：**
1. **初次访问** - 系统静默等待，不打扰正常浏览
2. **路由变化检测** - 自动感知页面/URL变化（支持SPA应用）
3. **智能询问** - 发现标注数据时，右上角弹出优雅提示框
4. **用户选择** - 点击"加载标注"启用系统，或"稍后"继续浏览

**标注操作：**
1. 选择要标注的文本（避免在输入框等可编辑区域）
2. 弹出工具栏，选择标注类型：
   - 🖍️ **高亮标记** - 黄色背景突出显示
   - **𝐁** **加粗框选** - 橙色边框+背景强调
   - U̲ **下划线** - 简洁的底线标记
   - ● **彩色标记** - 红/蓝/绿色背景标记
3. 标注立即生效，文本被智能包装，随页面自然移动

**快捷功能：**
- **Ctrl + Shift + G** - 快速切换标注显示/隐藏
- **自动检测** - 避免在已标注文本上重复标注
- **智能恢复** - 页面结构变化时自动重新定位标注

**数据管理：**
- 所有标注实时保存到本地存储（IndexedDB）
- 标注数据包含DOM路径和文本内容，确保高准确率恢复
- 支持跨页面、跨会话的标注持久化
- 通过扩展弹窗查看统计和管理数据

## 🎯 核心技术

- **DOM内联标注**：直接在网页HTML中嵌入标注元素，与页面布局完美融合
- **智能路由检测**：监听history API、popstate、hashchange实现全面的SPA支持
- **多重定位算法**：DOM路径+文本内容双重保障，确保标注准确恢复
- **Chrome Extension API**：使用 Manifest V3 规范，安全可靠
- **优化存储结构**：基于 `chrome.storage.local` 的高效数据组织方式
