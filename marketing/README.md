# GlassNote 商店海报

本组素材突出网页标注、学习博客、小说阅读、重开恢复与统一整理。五张主海报均为 1280 × 800；另外提供 440 × 280 小推广图和 1400 × 560 大推广图。

## 素材与使用

- posters/01-网页就是笔记本.png：总览，学习和在线阅读两个场景。
- posters/02-学习博客.png：小林笔记公开文章上的真实高亮和学习笔记。
- posters/03-小说阅读.png：原创小说《雾港来信》及真实高亮、下划线和阅读感想。
- posters/04-重开恢复.png：关闭小说标签页后重新打开同一页的前后截图，均为 3 条记录、3 处定位。
- posters/05-统一整理.png：实际笔记库中的 3 个网页、8 条演示记录，包含搜索、按颜色筛选和导出入口。

原始产品截图位于 source。只对截图做等比例布局和取景；未让生成模型重画界面或文字。玻璃背景由 OpenAI 内置 imagegen 生成，最终中文字、图标、真实截图和版式由 HTML/CSS 精确排版。生成提示词见 source/background-prompt.txt。

这组截图基于 GlassNote 3.0.1 的独立临时浏览器配置，不读取个人浏览器数据。博客截图来自 [小林笔记](https://xiaolinnote.com/agent/concept/agent.html)公开可见的引言；没有修改网页正文或绕过阅读限制。小说、日常资料及笔记库中的其他内容为原创演示数据；demo.test 地址只用于隔离测试环境。第三方文章与标识不属于 GlassNote 的 MIT 授权，详见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 复现排版

在仓库根目录安装开发依赖和 Playwright Chromium 后运行：

```sh
node marketing/render.cjs
```

渲染使用系统字体；macOS 上使用 PingFang SC。其他系统的字体回退可能改变字形或宽度，需要重新目检。

营销素材不会进入扩展发行包，本次不更改扩展权限、功能或版本。替换商店素材仍需经过 Microsoft 的更新审核。
