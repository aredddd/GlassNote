## 详细介绍

把网页，变成你的笔记本。

读技术博客、学新知识，或是在网页上追一本小说——看到重点，选中文字就能高亮；有了想法，直接写下笔记。GlassNote 让阅读、标注和整理留在同一个流程里，无需来回复制粘贴。

【读博客，边学边记】
在知识点、代码解释和重要结论上添加高亮、下划线或加粗。把自己的理解、疑问和复习要点记在网页里，之后可以从笔记定位回原文。

【读小说，留下感想】
喜欢的句子、人物伏笔、此刻的感受，都可以随读随记。多种颜色帮助区分不同内容；同一处格式再次点击即可取消，换色更新原记录，取消格式时附带的笔记仍会保留。

【这次记下，下次接着看】
标注即时保存，笔记点击保存后保存在当前浏览器本地。刷新或重开同一网页时，GlassNote 会结合摘录、上下文和文本位置重新定位。原文被删除或大幅改写、无法可靠定位时，笔记仍可在笔记库中查看。

【散落各处的笔记，一处整理】
所有网页的记录集中放进笔记库。搜索内容、按网页和颜色筛选、编辑和删除，或导出 JSON 备份。支持合并导入旧版数据和 v2 备份，相同 ID 的记录不会重复新增。

无需注册，无广告，无使用分析服务，不向开发者或第三方上传网页内容和笔记。所有数据在当前浏览器处理和保存，不提供云同步，建议定期导出备份。

适用于普通网页的主文档文本。浏览器内部页、扩展商店、内置 PDF 阅读器、Canvas、iframe 内文和封闭 Shadow DOM 不支持本版标注。本地 HTML 需要用户单独允许文件网址访问。网页变化可能影响定位；笔记按纯文本保存，不提供富文本编辑。

## 单一用途

帮助用户在网页中标注原文、记录阅读笔记，并在本地笔记库中整理和重新定位这些阅读记录。

## 权限用途

- storage：保存和读取标注、笔记、定位信息、页面信息与偏好设置，并读取旧版数据。
- activeTab：用户操作扩展弹窗时识别当前页面，显示当前页笔记并发送标注操作。
- scripting：用户操作扩展弹窗时，为尚未加载脚本的既有网页注入安装包内的内容脚本和样式。
- HTTP、HTTPS 内容脚本匹配：为了在再次访问已标注网页时自动恢复原文，并在用户选择文字时显示工具栏。读取当前页面地址、标题和正文用于本地定位，不遍历浏览器历史，不向服务器传输。
- file 内容脚本匹配：支持用户明确允许访问的本地 HTML；受浏览器的文件网址授权控制。

## 数据与远程代码披露

不使用远程代码。无开发者服务器、账号注册、广告、分析统计或网络上传。

扩展会在本地处理网页地址、标题、正文选区及上下文、用户笔记、标注设置和时间信息。商店的数据披露必须准确体现这种本地处理行为；不能笼统声称扩展不接触任何用户数据。具体用途、导入导出、删除和旧版迁移源保留方式见隐私说明。

## 审核测试说明

无需测试账号或登录。

1. 安装扩展后，刷新普通 HTTP 或 HTTPS 文章页。选择一段正文，点击高亮；再次点击应取消。下划线和加粗同样可切换。
2. 点击颜色添加彩色高亮；换色不会增加记录，再次点击当前颜色取消。
3. 选择正文并点击写笔记，输入文本保存。刷新或关闭网页再打开，笔记应保留；点击定位返回原文。
4. 在扩展弹窗打开笔记库，测试搜索、编辑、按颜色筛选、导出 JSON 和重复导入；重复导入不新增相同 ID 记录。
5. 隐藏标注后网页原文保持可见。若原文已删除或无法可靠定位，笔记仍可在列表中查看。

已完成本地自动化回归、真实 Manifest V3 扩展测试以及公开网页实测。测试记录是提交前验证证据，不代表 Microsoft 认证结果。
