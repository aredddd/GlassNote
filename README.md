# GlassNote

基于图层覆盖技术的网页标注浏览器插件。

## 🚀 快速开始

### Demo 体验

当前版本包含核心功能的可工作 demo：

**主要功能：**
- ✅ 文本选择和高亮标注
- ✅ 便利贴角标系统
- ✅ 多色彩标记（红/蓝/绿）
- ✅ 本地数据持久化
- ✅ 标注自动重现
- ✅ 扩展弹窗管理界面

### 安装方法

1. **下载源码**
   ```bash
   git clone https://github.com/aredddd/GlassNote.git
   cd GlassNote
   ```

2. **在 Chrome 中加载扩展**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择 `GlassNote` 项目文件夹
   - 扩展将出现在扩展栏中

3. **开始使用**
   - 访问任意网页（如 GitHub、文档站点等）
   - 选中文本，会弹出标注工具栏
   - 选择高亮、便利贴等功能进行标注
   - 使用快捷键 `Ctrl + Shift + G` 切换标注显示

### 使用指南

**文本标注：**
1. 在网页上选择要标注的文本
2. 在弹出的工具栏中选择标注类型：
   - 🖍️ 高亮标记
   - **𝐁** 加粗框选  
   - 📝 便利贴角标
   - U̲ 下划线
   - ● 彩色标记（红/蓝/绿）

**便利贴功能：**
1. 选中文本后点击 📝 按钮
2. 在弹出的对话框中输入便利贴内容
3. 保存后在文本旁会显示 📝 角标
4. 点击角标查看便利贴内容

**数据管理：**
- 所有标注自动保存到本地存储
- 重新访问页面时标注会自动恢复
- 点击扩展图标查看当前页面统计
- 可导出标注数据为 JSON 文件

## 🎯 核心技术

- **图层覆盖技术**：所有标注都是独立的 DOM 图层，不修改原网页结构
- **Chrome Extension API**：使用 Manifest V3 规范
- **本地存储**：基于 `chrome.storage.local` API 的数据持久化
- **智能定位**：基于文本位置和页面坐标的标注重现算法
